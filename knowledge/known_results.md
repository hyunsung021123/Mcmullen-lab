# knowledge/known_results.md — 알려진 결과와 이 저장소의 실측

이 파일은 **두 종류의 사실**을 엄격히 분리해 담는다.

- **§1 문헌 주장** — 사람이 원문으로 확인하기 전에는 `[출처 확인 필요]` 가 붙는다.
  **`[출처 확인 필요]` 가 붙은 항목을 계산의 전제나 논문의 인용으로 쓰지 말 것.**
- **§2~3 이 저장소의 실측** — 코드로 재현 가능하며, 재현 명령을 함께 적는다.

이 구분을 두는 이유: LLM 세션은 문헌 사실을 그럴듯하게 지어내기 쉽고, 그것이 한 번
지식베이스에 들어가면 이후 모든 라운드를 오염시킨다.

## 2. 이 저장소의 실측 — witness 존재/부재

전부 `om_core.mcmullen_evaluate` (또는 그와 동치인 `reorientation_cover`) 판정이다.

| (n, r) | d | GP-적법 uniform OM 수 | witness | 등급 | 재현 |
|---|---|---|---|---|---|
| (5, 3) | 2 | 192 | **없음** | 전수 | `research_cycle.py run --d 2 --n 5` |
| (6, 3) | 2 | 11,904 | 있음 (다수) | 전수 | `research_cycle.py run --d 2 --n 6` |
| (6, 4) | 3 | 1,920 | 없음 | 전수 (기존 CEGIS 기록) | `docs/RESEARCH_STATUS.md` |
| (7, 3) | 2 | 1,743,360 | — | 열거만 | 아래 §3 |
| (7, 4) | 3 | 1,743,360 | — | 열거만 | 아래 §3 |
| (8, 4) | 3 | 미측정 | 있음 (표본) | 표본 | `manager.py` 데모 기록 |

**주의**: 여기서 "GP-적법 uniform OM 수"는 χ(0,…,r−1) = +1 로 고정한 **전역 부호
대표계**의 개수다(=labeled chirotope 를 전역반전으로 나눈 것). 동형류(원소 재명명
포함) 수가 아니다. 기존 기록의 "(6,3) labeled witness 9,984개 = 3개 동형류"와
비교하면 9,984 / 11,904 ≈ 83.9% 가 witness 라는 뜻이고, 표본 측정치(84%)와 맞는다.

## 3. 이 저장소의 실측 — 열거 수치와 그로부터 나온 관찰

측정 명령:

```python
from generator import generate_backtracking
st = {}
n_total = sum(1 for _ in generate_backtracking(n, r, dedup=False,
              max_candidates=10**9, max_nodes=10**9, stats=st))
assert st["exhausted"]      # 캡에 걸리지 않았을 때만 '전수'
```

측정값 (2026-08-09, commit 은 실험 폴더 manifest 참조):

    (5,3)   192            0.0s
    (6,3)   11,904         0.1s
    (6,4)   1,920          0.0s
    (7,3)   1,743,360     31.6s
    (7,4)   1,743,360     32.0s

### 관찰 O-1 (VERIFIED, 범위 한정)

**(7,3) 과 (7,4) 의 개수가 정확히 같다** (둘 다 1,743,360).

rank r 인 uniform OM 과 rank n−r 인 그 쌍대 사이의 대응을 생각하면 자연스러운
현상이다(7−3 = 4). 이것은 §problem.md §4 에서 지적한 "n = 2d+2 에서 rank = corank"
구조와 같은 계열의 사실이며, **d=5 목표점 (12,6) 에서는 쌍대가 같은 rank 위의
대합이 된다**는 것을 시사한다.

⚠ 등급: 이 관찰은 두 수가 같다는 **실측**이지, 쌍대 대응이 witness 성질을 어떻게
옮기는지에 대해서는 **아무것도 말하지 않는다.** 쌍대에서의 convex 조건은 아직
확정되지 않았다(`problem.md` §4 말미).

### 관찰 O-2 (VERIFIED, 범위 한정)

(6,3) 에서 witness 비율이 약 84% 로 **매우 높다.** 즉 작은 차원에서는 witness 가
희귀하지 않다. d=5 에서도 그렇다면 무작위 탐색이 통해야 하는데 실제로는 안 통하므로,
**witness 비율은 차원에 따라 급격히 떨어질 가능성이 높다.** 이것을 정량화하는 것
(n, r 에 따른 witness 비율)이 값싸고 유익한 다음 실험이다.

## 5. 기록 규칙

1. 새 실측은 **재현 명령과 함께** 적는다. 명령 없는 수치는 신뢰할 수 없다.
2. 문헌 주장은 사람이 원문을 확인하기 전까지 `[출처 확인 필요]` 를 뗄 수 없다.
   LLM 이 출처를 제시해도 마찬가지다.
3. 틀린 것으로 밝혀진 항목은 지우지 말고 **취소선과 사유**를 남긴다.
4. "전수(exhaustive)"라고 쓰려면 `generate_backtracking(..., stats=)` 의
   `exhausted=True` 를 근거로 대야 한다.

## 6. d=5 프로젝트 착수 실측 (2026-08-09, `feasibility_probe.py` / `sweep.py` / `climb.py`)

### 관찰 O-3 (VERIFIED) — 후보 1개당 판정 비용

실현가능 무작위 점배치를 만들고 라벨(궤도 판정) + 저렴한 불변량 전체를 계산하는 비용:

    (n= 6, r=3) d=2      0.57 ms/후보    시간당 630만개
    (n= 8, r=4) d=3      3.73 ms/후보    시간당  97만개
    (n=10, r=5) d=4     24.69 ms/후보    시간당  15만개
    (n=12, r=6) d=5    172.27 ms/후보    시간당   2.1만개  (단일 코어)

대부분이 라벨 계산(2^(n−1) 재배향 마스크)이다. **d=5 개별 후보 판정은 실용적이다** —
README §10 의 "빠르다"를 정량화하면 172 ms 다. 12코어에서 초당 약 40~60개.

### 관찰 O-4 (VERIFIED) — 무작위 표집의 witness 밀도와 그 **급격한** 감쇠

    d=2 (6,3)    3,000개 중 2,266개    75.53%
    d=3 (8,4)    1,500개 중    24개     1.60%
    d=4 (10,5)  153,379개 중    0개     0%      (95% 신뢰 상한 0.002%)
    d=5 (12,6)      120개 중    0개     —       (표본 부족)

**d=2→d=3 의 감쇠 배수 47을 그대로 외삽하면 d=4 에서 0.034%, 즉 153,379개 중 약 52건이
기대된다. 실측은 0건이다 — 외삽 모형은 반증되었다.** 감쇠는 기하급수보다 훨씬 빠르다.

그런데 d=4 의 witness 는 **존재한다고 알려져 있다**(§1, Forge–Las Vergnas–Schuchert).
따라서 결론은:

> witness 는 존재하지만, 정수 격자 위 균등 무작위 표집으로는 사실상 도달할 수 없다.
> **d=5 에서 무작위 탐색(sweep)에 시간을 쓰는 것은 정당화되지 않는다.**

⚠ 등급: 이 관찰의 범위는 "[-C,C]^d 정수 격자 균등 표집, C ∈ {3,5,9,15,30}" 이다.
다른 표집 분포(예: 특정 대칭을 강제한 구성)에 대해서는 아무 말도 하지 않는다.

### 관찰 O-5 (VERIFIED) — 목적함수 국소탐색은 무작위보다 압도적으로 낫다

witness 를 0/1 이 아니라 연속 목적함수 `f = num_convex_reorientations` (0 이면 witness)
로 보고 국소탐색(`climb.py`)을 하면:

    d=4 (10,5)   무작위 153,379 표본의 최선   f = 4
    d=4 (10,5)   국소탐색 116,476 평가의 최선  f = 1     (5분, 10워커)

같은 정도의 계산량으로 f 가 4 → 1 로 내려갔고, 도달한 f 값의 분포가 매끄러운 기울기를
보인다(f=2 에 400회, f=1 에 1회 도달). **탐색 공간에 사용 가능한 기울기가 있다**는
뜻이며, 이것이 d=5 에 국소탐색을 적용할 근거다.

⚠ 아직 f=0 (실제 witness)에는 도달하지 않았다. 이 관찰은 "방법이 무작위보다 낫다"는
것이지 "witness 를 찾을 수 있다"는 것이 아니다.

### 방법론 규율 — d=4 를 먼저 보정 대상으로 쓴다

d=5 는 답을 모르지만 **d=4 는 답이 있다고 알려져 있다.** 그래서 같은 국소탐색을
(10,5) 에도 동시에 돌린다: 그것이 d=4 witness 를 실제로 재발견하면 방법이 검증되고,
못 하면 "이 방법으로는 d=5 도 안 된다"를 시간 낭비 전에 알 수 있다.
