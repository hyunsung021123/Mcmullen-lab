# knowledge/problem.md — 문제의 정확한 진술

이 파일은 **정의**만 담는다. 알려진 결과는 `known_results.md`, 정식화 사이의 관계는
`equivalent_formulations.md` 에 있다. 코드가 무엇을 계산하는지 헷갈릴 때 최종 기준은
`om_core.py` 이고, 이 문서는 그 코드가 **무슨 수학적 대상을 뜻하는지** 고정한다.

## 1. McMullen 문제

R^d 의 일반위치(general position) 점들에 대해:

> ν(d) = "일반위치의 임의의 ν(d)개 점 집합을, 어떤 허용가능한 사영변환으로
> convex position 으로 보낼 수 있다"가 성립하는 **최대**의 수.

- *일반위치*: 어떤 d+1 개도 아핀 종속이 아님.
- *convex position*: 모든 점이 그 볼록껍질의 꼭짓점. 동치로, **어떤 점도 나머지의
  볼록껍질에 속하지 않음.**
- *허용가능한 사영변환*: 어떤 점도 무한원으로 보내지 않는 사영변환.

**추측: ν(d) = 2d+1.**

### 계산의 목표가 "반례 찾기"가 아닌 이유

하한 ν(d) ≥ 2d+1 은 **이미 알려져 있다**(`known_results.md`). 따라서 "McMullen
추측의 반례"를 찾는 것은 목표가 아니다. 남은 것은 **상한**이고, 상한을 닫으려면

> n = 2d+2 개의 일반위치 점 배치로서, **어떤 허용가능한 사영변환으로도 convex
> position 이 되지 않는 것**을 하나 제시하면 된다.

그런 배치를 이 저장소는 **witness**(또는 obstruction)라 부른다. n 에서 witness 를
찾으면 ν(d) ≤ n−1 이 따라온다.

## 2. 이 저장소가 실제로 계산하는 것

### 2.1 표현

R^d 의 n 점 p_1,…,p_n → 동차화 (p_i, 1) ∈ R^{d+1} → **rank r = d+1 의 uniform
chirotope** χ: {r-부분집합} → {+1, −1}.

- uniform = 어떤 r 개도 선형 종속이 아님 (일반위치의 동차화 판본).
- 적법성: 3항 Grassmann–Plücker 관계. uniform 에서는 이것이 **필요충분**이며,
  `om_core.Chirotope.is_valid` 가 금지 부호패턴 (+,−,+)/(−,+,−) 만 검사한다.

### 2.2 사영변환 ↔ 재배향

원소별 부호반전 ρ ∈ {±1}^E 에 대해 χ^ρ(B) = χ(B)·∏_{e∈B} ρ_e 를 **재배향**이라
한다. 전역반전(모든 원소 반전)은 모든 판정을 보존하므로 원소 0 을 고정하고
재배향 공간을 (Z/2Z)^{n−1}, 크기 2^{n−1} 로 본다.

### 2.3 circuit = Radon 분할

uniform rank r 에서 circuit 은 정확히 (r+1)-부분집합 S 이고, 그 부호는

    C_{χ,S}(s_i) = (−1)^i · χ(S \ {s_i}),   S = {s_0 < … < s_r}

이다. 양의 부분과 음의 부분이 그 S 의 **Radon 분할**을 준다.

### 2.4 convex position 과 witness

    convex position(χ)  ⟺  모든 circuit 에서 min(|양|, |음|) ≥ 2
    witness(χ)          ⟺  2^{n−1} 개 재배향 중 convex position 이 되는 것이 없음

첫 줄의 근거: 점 p 가 나머지의 볼록껍질에 속함 ⟺ (Carathéodory) 한쪽이 {p} 인
Radon 분할이 존재 ⟺ 어떤 circuit 에서 작은 쪽 크기가 1. 그리고 작은 쪽이 0 인
경우는 양의 circuit(=acyclic 아님)이다. 따라서 "≥ 2" 는 두 조건을 한꺼번에 쓴 것이다.

둘째 줄에서 **모든** 재배향을 훑는 것이 **모든 사영상**을 훑는 것과 같은 이유:
convex position ⟹ acyclic 이고, 실현가능한 경우 acyclic 이 되는 재배향은 정확히
tope, 즉 어떤 선형범함수로 재정규화해 얻는 점배치에 대응한다. 그러므로 재배향
궤도 전체를 훑으면 사영상 전체를 훑은 것이다.

## 3. 절대 흐리면 안 되는 구분

### 3.1 세 상태는 서로 다르다

    acyclic         양의 circuit 이 없음                    (대표원소에 의존)
    totally cyclic  양의 cocircuit 이 없음 = acyclic 의 쌍대 (convex 와 무관)
    convex position 모든 Radon 분할이 균형                   (대표원소에 의존)
    witness         궤도 전체에 convex 가 없음               (궤도 불변)

앞의 셋은 χ 자체의 성질이고, witness 만 **궤도의 성질**이다. 어떤 양이 궤도 불변이
아니면 witness 와 동치가 될 수 없다 — `invariants.py` 가 이 분류를 실측해 기록하고,
`conjecture.py` 가 등급으로 강제한다.

### 3.2 추상 OM ≠ 실현가능 점배치 ⚠

GP 공리를 만족하는 chirotope 가 전부 실제 점배치에서 오는 것은 **아니다**
(비실현 유향 매트로이드). 그러므로:

| 찾은 것 | 증명되는 것 |
|---|---|
| **실현가능**한 witness, n=2d+2 | ν(d) ≤ 2d+1 ✅ 원 문제의 상한 |
| 실현가능성 **미확인** witness | 아무것도 — 실현가능성을 밝히기 전까지는 |
| **비실현** witness | OM 판본의 상한만. ν(d) 에 대해서는 아무 말도 못 한다 ❌ |

그리고 비실현 OM 이 실현가능 OM 보다 훨씬 많으므로, 추상 OM 탐색은 구조적으로
"아무 말도 못 하는 witness"를 먼저 만나게 되어 있다. 실험 폴더의
`scope.realizability` 항목이 매번 이 상태를 기록한다.

### 3.3 계산 결과의 등급

    PROVEN               사람이 증명함
    EXHAUSTED_ON_SCOPE   그 유한 범위에서 전수 확인 — 정리가 아니다
    UNRESOLVED           예산 안에서 반례를 못 찾음 — 증거로 약하다
    REFUTED              반례를 실제로 갖고 있음
    MINED / CONJECTURE   관찰됨. 아직 아무것도 아니다

"반례를 못 찾았다"는 증명이 아니고, "LLM 이 맞다고 했다"는 검증이 아니다.

## 4. 현재 목표

| d | rank r | 목표 n = 2d+2 | 상태 |
|---|---|---|---|
| 2 | 3 | 6 | witness 존재 확인 (이 저장소 전수) |
| 3 | 4 | 8 | witness 발견 사례 있음 |
| 4 | 5 | 10 | 문헌에 결과 있음 — `known_results.md` 참조 |
| **5** | **6** | **12** | **미해결 — 본 목표** |

d=5 에서 chirotope 는 C(12,6)=924 비트라 공간이 2^924 이다. 전수 열거는 불가능하고,
대칭군 (Z₂)^11⋊S₁₂ (크기 ≈ 10^12) 로 나눠도 여전히 불가능하다. 따라서 필요한 것은
**구조적 후보족**(파라미터화된 구성)이며, 그것을 제안하는 것이 고급 모델 세션의
주된 임무다.

### 구조적 힌트 (검증 대상이지 기정사실이 아님)

n = 2d+2 에서 rank 는 d+1, corank 는 (2d+2)−(d+1) = d+1 로 **같다.** 즉 목표
크기에서 OM 의 rank 와 쌍대 rank 가 일치한다. Gale 쌍대가 같은 rank 위의 대합이
되므로 탐색 공간을 쌍대로 접거나, 자기쌍대 구성만 겨냥하는 축소가 가능할 수 있다.
`falsify.py` 로 얻은 열거 수치가 이 방향의 정합성 점검을 준다
(`known_results.md` §3).

**단, convex position 조건이 쌍대에서 정확히 무엇이 되는지는 이 저장소에서 아직
확정하지 않았다.** 문헌(Björner–Las Vergnas–Sturmfels–White–Ziegler) 대조 전에는
쌍대 조건을 코드로 구현하지 말 것.
